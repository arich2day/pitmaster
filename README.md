# PitMaster

PitMaster is a first person 3D barbecue simulator that runs in the browser. You walk the yard, tend the cookers, and serve orders before patience runs out.

## What is in the game

7 cookers, including a vertical pellet smoker and a horizontal pellet grill.
12 meats, each with target temperatures and cook times.
Real fuel. Load charcoal, wood splits, and pellets. Fuel burns down and temperature collapses until you reload.
6 smoke woods, each with its own flavor, smoke, and burn effects.
A supply shop. Order coal, pellets, wood, and meat cases with cash from the till.
Weather that changes as you cook.
Simulated time with a full day and night cycle, so long cooks run past dark.
3 modes: Service Rush, Competition against 3 rival pitmasters, and Free Smoke.

## How to play

Open index.html in a browser. Click to lock the mouse, walk with WASD, look with the mouse, and use the on screen prompts at each station. A gamepad works too.

Built with Three.js. No build step and no server needed.
